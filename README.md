## 安装

1. 下载本仓库并解压，或者解压上面的插件安装包。
2. 在 Chrome 打开 `chrome://extensions/`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的 `imagegrab-extension/`。
4. 在插件匹配的网站打开页面，点击右下角“获取图片”。
5. 在画廊中检查并勾选图片，点击“下载选中”。

本次成功的真实站点验证为淘宝；清单中配置的其他电商域名不等于已经逐站测试通过。

## 本地归档检查

```powershell
node scripts/verify-snapshot.cjs
powershell -NoProfile -File scripts/verify-downloads.ps1 -CollectionRoot "你的采集目录"
```

`verify-snapshot.cjs` 检查插件源码和归档时的哈希是否一致，并检查结果清单的一致性。它不重新访问淘宝，不替代真实站点测试。

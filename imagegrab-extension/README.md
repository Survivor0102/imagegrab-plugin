# 图提取 · ImageGrab

1.3.0 在商品图片提取之外新增 1688 选品研究台和榜单自动分页采集。加载扩展后，在 1688 页面点击“加入选品研究”或“自动采集榜单”；也可点击浏览器工具栏中的扩展图标打开研究台。

- 商品档案和多货源报价对比
- 页面可见商品字段与图片链接收集
- 最多 1000 个去重商品的分页采集，可随时停止
- CCC 等认证记录及待核验状态
- CSV 导出、JSON 本地备份与恢复

详细说明见仓库 `docs/1688选品研究台.md`。模拟分页测试已通过；真实榜单分页及字段识别尚未验证。

一个基于 Manifest V3 的 Chrome 电商图片提取下载插件。

## 支持平台

- 淘宝 / 天猫
- 京东
- 拼多多商家版相关域名

## 本地安装

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录（包含 `manifest.json` 的 `imagegrab-extension` 文件夹）。
5. 打开支持的商品详情页，点击右下角“获取图片”。

## 设计说明

- `content.js` 负责扫描 `img`、`srcset`、懒加载属性和背景图。
- `background.js` 负责在扩展页面之间传递结果并调用下载权限。
- `gallery.html` / `gallery.js` 提供勾选、反选、批量下载和 PNG 转换。
- 跨域服务器不允许 CORS 时，插件会提示并启动原图兜底下载；这是浏览器安全策略限制。

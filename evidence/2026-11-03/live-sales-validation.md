- 浏览器：课程专用 Chrome for Testing 154.0.8037.98，Profile 2，已由用户登录的既有会话；通过登记器核验 `127.0.0.1:9333`，未启动或关闭浏览器。
- 扩展：`C:/Users/ASUS/Desktop/插件/imagegrab-extension`。重载后发现 Chrome 开发者模式关闭，未打包扩展处于停用状态；开启开发者模式后启用扩展，并在扩展管理页确认版本。
- 搜索页：当前登录会话已打开淘宝“女包”搜索结果页，页面可见商品标题和“人付款”文字。点击 ImageGrab“获取图片”，由扩展打开自己的画廊页。
- 首轮 1.1.0 失败：74 张候选图全部没有商品上下文。只读检查 DOM 后确认新版淘宝卡片链接为 `click.simba.taobao.com/cc_im` / `mclick.simba.taobao.com/cc_im`，不匹配此前只接受商品详情规范链接的规则。
- 修正：增加淘宝搜索跟踪链接识别，并优先从卡片独立标题节点提取标题；补充仿真集成测试，版本提升为 1.1.1。重载同一扩展目录并刷新搜索页后复测。

## 搜索页结果

- 复测批次：画廊显示 73 张候选图片。
- 最终 1.1.1 复测：72 张候选图中 69 张识别到商品标题和页面可见销量文字，68 张识别到商品链接。未识别项保持未识别状态。
- 示例：标题“COACH/蔻驰奥莱女士老花LAUREL31号手提包单肩包斜挎包流浪包通勤”对应页面原文“2万+人付款”，链接来自该商品卡片的淘宝 `click.simba.taobao.com` 跟踪链接。
- 该计数是图片候选与商品卡片上下文的关联数，不是不同商品数、有效图片数或销量准确率评估。一个商品的多张图片可重复显示同一商品信息。

## 详情页结果与边界

- 从搜索结果卡片使用其可见商品 ID 打开对应淘宝商品详情页。页面展示淘宝“访问异常提示”，同时仍呈现商品基本信息；未尝试绕过、重复请求隐藏接口或更换身份规避限制。
- 因平台提示，真实详情页的销量关联未能完成验证。详情页扫描逻辑仅有仿真 DOM 集成测试支持，保持未验证。
- 实测使用过的查询词为当前页面已有的“女包”，没有开展额外关键词搜索或批量采集。

## 判定

不能承诺“下载仓库后即可保证复现”。仓库保留了当次源码、实际调用摘录、返回结果和文件检查，但登录态及浏览器资料本地保管；历史自动化是在持久 Node REPL 中完成，早期归档的批次函数不是独立程序。

## 本次实测

- `npm ci`：成功安装锁定依赖 Playwright 1.62.1（浏览器使用 CDP，不下载 Playwright 自带浏览器）。
- `npm test`：4 项单元测试通过。
- `npm run verify`：8 个插件源码文件哈希匹配，300 条图片文件元数据清单通过内部一致性检查。
- `npm run doctor`：失败。它连接到 Chrome 154.0.8037.98 和原课程 `Profile 2`，可访问已登录淘宝首页，但当前页面没有 ImageGrab 的“获取图片”按钮。
- `npm run smoke`：未运行。doctor 未通过时不继续。
- `npm run collect`：未运行。

## 因此保留的边界

采集操作说明保留了当时成功发生的顺序和参数，不代表当次机器环境可以不经配置移植。需要用户 Profile、CDP、扩展注入、淘宝当前可访问、下载完成，以及输出文件校验。仓库不含登录资料、浏览器可执行文件、浏览器 Profile 或300张图片本体。

新加入的 `scripts/collect.cjs` 是归档后重建的独立运行器，尚未通过一次真实 smoke。它当前不能被宣称为已证明可复现。

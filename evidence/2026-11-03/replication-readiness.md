## 本次实测

- `npm ci`：安装锁定依赖 Playwright 1.62.1。
- 启动：复用历史成功的 Node `child_process.spawn` 流程，指定原课程资料根、Profile 2、Chrome for Testing 154.0.8037.98、CDP 9333，并在同一实例传入 `--load-extension` 和 `--disable-extensions-except`。
- `npm test`：5 项单元测试通过。
- `npm run verify`：归档插件源码快照和 300 条历史图片记录通过一致性校验。
- `npm run doctor`：通过；确认真实 Profile 路径、淘宝页可读且 ImageGrab 按钮存在。
- `npm run smoke`：3/3 张实际下载并复制到项目输出目录，三张文件均非空且 PNG 文件头正确。
- `npm run collect`：运动鞋第 1、2 页各 50 张成功保存并验证，共 100 张；按用户要求中止，剩余批次未完成。部分运行记录保留在本机被忽略的 `output/` 下，不上传图片本体。

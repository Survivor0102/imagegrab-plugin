# 普通 Chrome 真实榜单验证

记录日期：2026-11-04（工作区日期）。扩展版本：1.3.1。

## 实际环境与接入

使用用户已打开并授权的普通 Google Chrome 155.0.8059.86，实际资料目录是普通用户资料根下的 Default。用户启用浏览器内置远程调试，并允许本地调试连接。没有重启这个 Chrome，也没有复制登录数据库。

该模式在本机监听 127.0.0.1:9222。HTTP /json/version、/json/list 返回 404，Playwright connectOverCDP 在本次环境中超时。最终采用 DevToolsActivePort 中的实际 WebSocket 路径与 Node 原生 WebSocket，直接发送 CDP 命令，连接及页面操作成功。没有把普通 Chrome 改造成原课程的 Chrome for Testing。

扩展通过 Extensions.loadUnpacked 实际加载，随后使用 chrome.developerPrivate.reload 更新，刷新任务榜单标签使新内容脚本生效。研究台数据来自已安装扩展的 chrome.storage.local，不是替换页面 chrome 对象得到的模拟结果。

## 本次修复

1. 榜单使用无商品超链接的React点击卡片，原先只搜索offer锚点导致采集0条。后台在MAIN世界读取对应卡片ID，内容脚本负责页面动作；只接受匹配榜单的顶层发送者。
2. 保留月销量标签和值，支持K/M；将分段渲染的价格整理为 ¥0.01。
3. 列表自身滚动，滚动整个window无效。现优先滚动卡片所属的可滚动祖先。
4. 自动任务绑定发起标签，支持停止、去重和未变化时停止。研究结果在后台标签打开。
5. 修复点击处理器的async语法错误；单页没有识别到商品时不再打开空结果台。

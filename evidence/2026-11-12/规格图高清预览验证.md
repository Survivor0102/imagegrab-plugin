# 规格图高清预览验证

日期：2026-11-12

记录范围：以下为1.9.3修复前的现场调查。后续已实现1.9.4并完成真实Chrome只读采集验证，见[修复实测](规格图高清预览修复实测-1.9.4.md)；下文的“仍未实现”为调查时状态。

## 结论

当前 ImageGrab 1.9.3 的代码能够采集详情页中已经渲染在规格按钮或规格行内的图片，但没有证据表明它会点击规格图片、读取弹出的高清预览层，或把缩略图 URL 转换成高清原图 URL。因此，用户看到“详情页点击规格后清晰，选品台保存后模糊”的现象与当前实现相符。

本轮完成了源码核对、本地测试和真实 1688 页面现场对比。第一次连接使用旧标记失败；随后在同一真实普通 Chrome 中成功建立连接，并在后台新开详情页完成只读验证。没有修改选品台数据，也没有启动批量补全。

## 源码证据

- `imagegrab-extension/detail-capture.js:9-17` 的 `images()` 只取 `img.currentSrc`、`src`、`data-src` 或 `data-original`。
- `imagegrab-extension/detail-capture.js:35` 只在 `#skuSelection` 内寻找 `.sku-filter-button img` 和 `.expand-view-item img`。
- `imagegrab-extension/detail-capture.js:38-46` 将规格按钮或规格行内读取到的 URL直接写入 `selectedOptions.imageUrl` 和 `sku.imageUrl`；没有点击图片预览、读取外层弹窗或解析高清候选。
- `imagegrab-extension/offer.js:75-82` 将已保存的 `sku.imageUrl` 直接作为二级页面的 `<img src>`，所以如果采集时得到的是缩略图，二级页面会继续显示缩略图。

## 现有测试覆盖范围

`npm test` 已通过 66 项测试，包含“规格组合切换、售罄规格展开、规格行图片关联、报价读取、选品台展示和图片下载”。现有测试使用合成页面验证规格行图片 URL，例如 `https://img.test/silver.jpg`，没有模拟下面这个关键场景：

1. 规格按钮中的图片是缩略图；
2. 点击规格后，高清图在规格图片预览层或其他弹层中出现；
3. 规格按钮本身仍保留缩略图；
4. 采集器需要从弹层读取高清图并替换原 URL。

因此，66 项通过不能证明高清预览图已经被采集。

## 真实页面现场结果

页面：`https://detail.1688.com/offer/895666369320.html`

商品标题：`小鼻嘎捏捏解压玩具包挂烂泥手感汉堡食玩仿真盲盒迷你减压挂件`

选取规格：`黄色猪仔包小鼻嘎`

点击前后规格行图片均为：

```text
https://cbu01.alicdn.com/img/ibank/O1CN01UyQQE325ViE6CwyPw_!!2216808817532-0-cib.jpg_sum.jpg
naturalWidth=80, naturalHeight=80
```

页面同时存在对应高清图：

```text
https://cbu01.alicdn.com/img/ibank/O1CN01UyQQE325ViE6CwyPw_!!2216808817532-0-cib.jpg_.webp
naturalWidth=1920, naturalHeight=1920
class=ant-image-img preview-img
```

高清图位于页面的 `.od-gallery-list` / `.od-gallery-preview` 图片节点中；规格行本身没有把 `src` 替换为高清地址。

将当前 `detail-capture.js` 注入同一真实页面后，`ImageGrabDetail.collect()` 返回该规格的 `imageUrl` 仍为 `jpg_sum.jpg`，`imageAssociation` 为 `sku-row`。因此“详情页高清、选品台模糊”的原因已被真实页面和当前代码共同验证。

## 下一步修复条件

如果要修复，需要在不改变当前规格关联关系的前提下，为规格图片增加高清候选解析：

1. 读取规格行缩略图和点击后页面中对应的高清图；
2. 建立缩略图 URL 与高清图 URL 的关联；
3. 在详情采集结果中保存高清 URL，同时保留原始缩略图 URL 作为来源证据；
4. 在合成测试中覆盖 `jpg_sum.jpg` 与 `jpg_.webp` 的替换场景；
5. 再用同一真实商品验证规格行、选品台预览和下载文件的尺寸；
6. 修复前不覆盖现有选品台记录。

本轮现场验证已完成；高清原图读取仍未实现，也没有修改历史采集结果。

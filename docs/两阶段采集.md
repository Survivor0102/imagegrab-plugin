# 两阶段采集

版本：1.6.0。

## 第一阶段：收集链接

在1688榜单或搜索结果页点击左下角的“自动采集榜单”。插件尝试滚动加载或翻页，按商品链接去重。停止后将已采到的商品导入研究台。程序上限1000不代表榜单必定能加载1000条；当前真实榜单曾加载20条。

“加入选品研究”仍保留，用来只采集当前页面一次。在商品详情页中，它只读取当前所选选项，不执行第二阶段的批量遍历。

## 第二阶段：补全详情

1. 切到“选品研究台”标签页，在概览下方找到“第二阶段 · 商品详情”。
2. 选择“当前筛选的商品”“当前选中商品”或“全部商品”。当前筛选包含满足来源筛选和搜索条件的商品；若只采集一个商品，先点击其列表行，再选“当前选中商品”。
3. 点击“批量补全详情”。队列包含所选商品的各条1688货源链接；链接去重，已有完整选项采集记录的货源自动跳过。
4. 插件创建一个后台标签页，按链接顺序加载商品，等待标题、价格和规格模板，采集参数、供应商、发货地、页面销量、包装及媒体链接，并切换颜色、型号等可见选项，展开售罄规格。
5. 每件商品采集后直接保存到原货源，研究台同步刷新。点击“逐件采集记录”核对完成、跳过、部分完成或失败，以及规格行数、媒体链接数。
6. “停止补全”保留完成结果；再次点击“继续 / 重试未完成”，只重新处理待采集、异常或部分完成的条目，不重采已完成条目。

任务和逐件状态保存在本浏览器。研究台标签页关闭后，后台任务继续；浏览器/服务工作线程中断后保留队列，重新运行时检查并重试中断的条目。连续中断超过3次会记录失败，避免反复打开同一商品。浏览器关闭期间无法继续采集。

## 验证、失败与资料保护

- 遇到登录或安全验证时暂停，保留任务标签页供用户完成验证；完成后点击“继续 / 重试未完成”。不自动操作验证码。
- 不占用其他已有商品页、不切换用户当前标签；任务页由插件单独创建。用户若把任务页导航到其他页面，插件暂停并保留该页面。
- 详情补全期间可查看及导出档案；编辑、删除和导入暂时锁定，停止后可操作。榜单自动采集与详情补全不能同时启动。
- 排名、榜单销量、手写备注、认证记录和其他货源分别保留。详情中的销量另存来源记录，不冒充榜单月销量。
- 某些选项组合不可选、未激活或单件超过约210秒时会记录“部分完成”；不把缺失值补成猜测。单件最多尝试600个选项组合。
- 尚未适配的详情模板会显示超时或失败；已有完整详情不会被本次部分结果覆盖。

## 图片文件

第二阶段保存的是商品资料、规格关联和图片链接。查看某一货源的“规格与图片”，可导出CSV/JSON并点击“下载全部图片”保存实际文件。此版没有将批量图片下载加入第二阶段，以免一次任务自动产生大量文件。

## 测试入口

`npm test` 包含队列顺序、去重、停止/续采、验证暂停、失败与部分结果、工作线程恢复、既有数据保护、真实DOM颜色切换与价格图片关联，以及研究台按钮的范围和进度测试。网络及Chrome API在这些测试中使用夹具；真实1688验证须另以当前版本的实测证据为准。

2026-11-04全套28项通过。其中安装扩展的集成测试使用独立、用后清理的Chrome for Testing资料目录，实际加载1.6.0扩展，由真实Chrome存储、消息、后台脚本和标签页API连续处理两件商品；商品页面由测试路由提供，每件两种颜色，两行规格与对应价格/图片核对通过，当前前台标签保持不变。证据：`evidence/2026-11-04/detail-job-installed-fixture-1.6.0.json`。这项测试不使用用户登录资料，不是访问真实1688的实测。

本轮普通Chrome的单次调试连接等待授权超时后已结束，没有重复连接。日常Chrome仍需重载新版扩展，并对真实1688商品补做第二阶段验证。

安装更新后，在 `chrome://extensions/` 重载ImageGrab，再刷新研究台和榜单页。安装目录是项目的 `imagegrab-extension/`；源码目录与ZIP安装包是同一版本的不同使用入口。

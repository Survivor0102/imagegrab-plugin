# 1688 选品研究台 MVP

版本：ImageGrab 1.4.0。研究台在浏览器本地保存数据，不连接远端服务。

## 已实现

- 在 1688 商品列表或详情页点击“加入选品研究”，整理当前页最多 100 条候选。榜单页可点击“自动采集榜单”，按页面可见分页逐页采集，最多 1000 个去重商品；页面标题或链接像是榜单时标记“榜单”，识别不到的排名留空，可在档案编辑时补录。
- 创建商品档案，记录标题、品牌、类目、排名、来源链接、图片链接、规格参数和产地。
- 为同一商品添加多家候选货源，比较供应商、页面价格、起订量、可见成交文字、地区和资质备注。先选中已有商品，再把新捕获的候选并入其货源；合并前会要求确认。
- 记录 CCC 等认证类型、证书编号、机构、核验状态和证据链接。新记录默认“待核验”，不会因为页面出现认证字样自动标记通过。
- 搜索、来源筛选、CSV 导出和 JSON 完整备份/恢复。
- 详情页只采当前商品，按规范化商品URL补充已有档案。保存结构化参数、SKU报价库存、共享选项图关联、图片角色、包装、视频、供应商指标和各来源销量原文。
- 点击商品档案中的“在 1688 搜同名货源”会打开关键词搜索页。以图搜货从商品档案打开来源商品或图片，再在 1688 页面使用平台当前提供的以图找货入口；找到候选后点击“加入选品研究”，然后合并到原商品档案。

## 使用

1. 在 `chrome://extensions/` 开启开发者模式，加载本目录的 `imagegrab-extension/`。
2. 打开 1688 榜单页、搜索结果页或商品详情页。单页采集点击“加入选品研究”；要连续采集榜单时点击“自动采集榜单”，完成后会进入研究台。
3. 在研究台检查捕获内容，编辑商品档案；逐个添加需要比较的供应商货源。
   补详情时打开商品链接，等待参数与规格加载，滚到“商品详情”等待图片出现，再点“加入选品研究”。研究台自动补充同一档案，展示规格、图片角色、供应商与销量来源。JSON保留所有结构化数据；CSV增加参数、SKU、图片角色及销量来源JSON列。
4. 自动采集会尝试点击可用的下一页，指定新版榜单则滚动商品列表内部。完成后点击浏览器工具栏的扩展进入研究台；采集结果也会在后台标签打开。遇到无法识别的页面可手动翻页再单页采集。完成后导出 CSV 筛选，定期导出 JSON 备份。

## 字段边界

- 页面采集是启发式读取当前可见 DOM。1688 页面结构、登录状态和商品卡片模板变化可能导致标题、价格、销量、起订量或供应商漏识别；采集后需检查并手动补齐。
- 每个商品和货源的字段分开保存。同一商品下新增不同供应商时，从商品档案点击“添加货源”，不要把不同商品误并为同款。
- 图片目前保存图片 URL 并在档案预览，不自动下载整页图片。确需图片文件时可从来源页面使用原有图片提取画廊，检查后手动下载。
- CCC、产地、品牌、规格和供应商资质均是待核信息。工具不会仅凭商品标题/详情页文字确认真实性，也不会自动获取认证数据库内容。
- 自动采集支持可见下一页控件和 `air.1688.com/kapp/1688-global/sales/ranking` 的商品列表滚动，不调用隐藏接口。新版榜单没有商品 `<a>` 链接，扩展后台通过 `chrome.scripting.executeScript` 在主世界读取卡片的 React 商品 ID，再构成详情链接。名称、价格和月销量优先来自卡片 DOM；未出现的供应商和排名留空。
- 最多保存 1000 个去重商品；可随时停止。遇到验证、重复页面、未识别商品或页面未变化时停止。滚动等待超时只表示本次没有检测到新增商品，不证明网站不存在后续数据。任务绑定发起标签，其他标签不会自行接续。
- 自动采集需要当前榜单已打开并可正常浏览；不会自动登录或处理验证码。1000 是保存上限，受页面及账号条件影响，不保证能跑满。
- “销量/成交”仅保留页面原文字样，不把不同口径换算成精确销量。排名页是否真实代表销售额、订单量或平台综合排序，应以榜单自身说明为准。

## 验证状态

本地18项测试通过，包含后台读取函数与模拟消息通道、无链接React卡片、月销量、列表滚动、分页去重、停止、标签隔离及详情档案补充。这些夹具不等于真实站点验证。

1.4.0已真实验证单件木珠详情：11项参数、15个SKU、6主图链接、11详情图链接及1颜色图链接，原20条档案未增加重复记录。产地与CCC保持缺失。详见[单商品详情实测](../evidence/2026-11-04/商品详情实测记录.md)。下一段为之前1.3.1榜单测试的历史范围；本次补充了单件详情，其他批量范围仍未验证。

2026-11-04 已在普通 Chrome 155 的 Default Profile 实际加载扩展，采到真实“全网销量榜 / 工艺品”20 个商品，逐条标题、价格、月销量与页面一致。列表滚到底后未出现新卡片，扩展按预期停止；没有验证实际连续第二批、1000 条全量、目标美妆/日用/婴幼儿榜单、供应商详情和 CCC。见 [真实记录](../evidence/2026-11-04/ordinary-chrome-live-validation.md)。

可用 `npm run test:live-1688` 在临时隔离的未登录 Chrome Profile 中做一次公开搜索页小范围冒烟测试。它不会使用或修改已经登录的业务 Profile；遇到登录跳转、安全验证或页面结构不符时会报告阻塞并停止。公开搜索页冒烟结果不能替代目标 Top1000 榜单页的真实验证。真实列表验证需要用户已登录的目标 Profile 可用，并经浏览器工作区租约登记后进行。

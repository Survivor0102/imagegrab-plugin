# 规格替代寻源

## 作用

“规格替代寻源”是寻源工作区的第三个分支，和原来的“图片 / 名称筛选”“截图自动寻源”并列。它面向两类候选：

- 同品牌候选：优先核对目标品牌是否出现在标题或可见资料中。
- 不同品牌但可能替代的候选：保留候选，后续按规格、用途和资料继续核对。

这个分支不把候选直接判定为同款，也不会覆盖前两个分支的候选池。它使用 `imagegrabSourcingSubstituteData` 独立保存状态。

## 使用顺序

1. 打开研究台的“寻源工作区”，点击“规格替代寻源”。
2. 填写商品名称、品牌线索、商品大类和目标规格；也可以上传 1～2 张参考图。
3. 选择“完全一致”或“允许差异”。第一版的“允许差异”会保留同单位但数值存在差异的候选，并在卡片中提示规格差异。
4. 打开 1688 名称搜索或图片搜索。
5. 回到研究台，刷新标签列表，选择 1688 结果页，点击“读取该页候选”。可以重复读取多个结果页，插件按商品链接去重并保留来源。
6. 点击“标注并筛选”。候选卡片会显示：品牌关系、目标规格状态、规格差异、供应商和货源链接。
7. 搜索结果页没有展示规格时，状态会保留为“尚未核对”；勾选候选后使用“详情补全”，再在商品池中检查详情页规格、发货地、客服链接和资料线索。
8. 只有确认需要保留的候选才点击“加入商品池”；也可以直接点击“详情补全”，它会先加入商品池再启动详情任务。

## 标签含义

- 品牌关系：同品牌、不同品牌、品牌未识别。
- 目标规格：包含目标规格、不包含目标规格、尚未核对。
- 资料状态：详情补全后仍需根据页面证据判断，页面自述不自动等同于认证材料。

“尚未核对”表示搜索结果页信息不足，不表示不符合。详情页存在多个规格时，只要其中一个规格包含目标规格，就应继续保留并人工核对对应的规格图片、价格和资料。

## 当前边界

- 第一版规格抽取以名称、图片 OCR 线索和用户修正为输入；没有强行给所有品类建立固定规格模板。
- 当前的规格判断主要使用页面可见文字和数值单位；复杂参数、组合 SKU、用途替代关系仍需详情页补全后复核。
- 同品牌和不同品牌在同一批候选中收集，不要求重复搜索两遍。
- 详情补全沿用现有第二阶段任务；候选在加入商品池时保留“规格替代候选，尚未确认同款”的证据标记。

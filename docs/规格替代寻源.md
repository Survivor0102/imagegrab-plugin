# 规格替代寻源

## 作用

“规格替代寻源”是寻源工作区的第三个分支，和原来的“图片 / 名称筛选”“截图自动寻源”并列。它面向两类候选：

- 同品牌候选：核对详情属性或明确品牌字段；标题提到品牌仅作为线索。
- 不同品牌但可能替代的候选：保留候选，后续按规格、用途和资料继续核对。

这个分支不把候选直接判定为同款，也不会覆盖前两个分支的候选池。它使用 `imagegrabSourcingSubstituteData` 独立保存状态。

## 使用顺序

1. 打开研究台的“寻源工作区”，点击“规格替代寻源”。
2. 填写商品名称、品牌线索、商品大类和目标规格；也可以上传 1～2 张参考图。
3. 选择“完全一致”或“允许差异”。完全一致会排除已有明确冲突的候选；允许差异会保留到待核对组，仍明确显示冲突，不将差异算成匹配。
4. 打开 1688 名称搜索或图片搜索。
5. 回到研究台，刷新标签列表，选择 1688 结果页，点击“读取该页候选”。可以重复读取多个结果页，插件按商品链接去重并保留来源。
6. 点击“标注并筛选”。候选卡片会显示：品牌关系、目标规格状态、规格差异、供应商和货源链接。
7. 规格资料缺失时显示“规格证据不足”；勾选候选后使用“详情补全”。补全保存后会自动刷新规格判断，也可重新点击“标注并筛选”。已有详情会直接用于核对，无须重复联网采集。
8. 只有确认需要保留的候选才点击“加入商品池”；也可以直接点击“详情补全”，它会先加入商品池再启动详情任务。

## 标签含义

- 品牌关系：详情明确字段支持“同品牌 / 不同品牌”；只有标题线索时显示“疑似同品牌 / 疑似不同品牌”，无可靠线索显示“品牌待核”。`other`、其它、无品牌、空字段不等于不同品牌；品牌字段相互冲突也保留待核。
- 目标规格：已知条件匹配、存在规格冲突、规格证据不足。卡片显示核对项数、缺失项数和冲突项数，并列出依据。
- 资料状态：详情补全后仍需根据页面证据判断，页面自述不自动等同于认证材料。

“规格证据不足”不表示不符合。名称和规格字段会共同提供已知条件，例如“全塑料筒灯 12W”同时要求塑料和12W。详情有多个SKU时，必须有同一行SKU同时满足这些条件，不能从不同选项拼接。`12瓦`与`12W`、`12cm`与`120mm`可换算比较；开孔和直径分别处理。

“已知条件匹配”只表示提供的条件得到页面支持，不表示已证明可直接替代。目标没有提供的电压、开孔、安装方式等不会凭空补成相同。通用塑料条件可被PC材质满足，但不因此推断具体塑料配方相同。任意品类还可填写`颜色：白色；容量：500ml`等属性；没有预设所有品类的专用模板。

## 当前边界

- 第一版规格抽取以名称、图片 OCR 线索和用户修正为输入；没有强行给所有品类建立固定规格模板。
- 比较使用当前货源详情属性、SKU行和商品标题，详情结构化字段优先于搜索标题；每个判断保留来源。图片中的参数仍需OCR或人工补充，复杂参数、组合SKU及用途替代关系仍需复核。
- 同品牌和不同品牌在同一批候选中收集，不要求重复搜索两遍。
- 详情补全沿用现有第二阶段任务；候选在加入商品池时保留“规格替代候选，尚未确认同款”的证据标记。

## 1.9.9修正

修正1.9.8把“没命中目标品牌”判为“不同品牌”、只凭12W标成“包含目标规格”的问题；详情补全后同步更新候选卡片和货源证据。新分支默认优先展示20件，原两个分支的默认值保持原设置。

## 1.11.1前20条待核队列

默认数量20指本轮要继续核对的数量；优先候选排在前面，资料不足的待核对结果接在后面，已排除项不进入队列。点击“勾选前N个待核候选”按当前数量选择；不会把待核对改成匹配成功。独立候选同步到1688_you后，可选择“本轮前20个待核 / 补全”查看。这是候选队列，详情采集仍需在插件点击“详情补全”。已有“详情补全”会先将选择的记录加入商品池。

## 1.11.2搜索卡片字段恢复

历史候选卡已保存文本但结构化报价、销量、供应商为空时，在评估和显示时从本卡文本恢复，保留来源；不必为这些已有信息重新搜索。新采集兼容 `¥ 8 .9` 的分段小数和 `已售200+件`，无店铺链接时读取本卡独立店名行，不从相邻卡片借用供应商。

品牌标题线索只是待核证据，不能代替详情明确品牌。供应商名称中的地区不自动变为发货地，标题出现12W也不能证明所有目标条件由同一SKU满足。真实理星照明候选已在普通Chrome 1.11.2核对：显示¥8.9、供应商和疑似不同品牌，塑料材质仍待核。详见 `evidence/2026-11-18/插件字段恢复_普通Chrome实测_1.11.2.json`。

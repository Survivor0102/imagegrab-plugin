# 其余19件商品批次下载

本次范围是原工艺品榜单20件商品中，除已完成的木珠货源 `678400004650` 外的19件。不是新搜索19件，也不是19家不同店铺的同款比较。

## 结果与本地入口

19/19件完成，762行规格报价，579个图片文件；图片及各商品CSV/JSON共82,633,018字节。全部图片经过非空、Pillow实际解码、尺寸和SHA-256检查；CSV行数、JSON规格数、商品URL以及规格图到实际本地文件的关联核验通过。研究台仍是20件商品、20条货源，没有因补采新增重复档案。

本地唯一交付位置：`output/2026-11-04-其余19件商品-规格与图片/`。先看README或商品总览CSV。每件商品一个目录，含主图、详情图、选项图、规格报价CSV、货源资料JSON和文件核验清单；总目录另有全部规格报价汇总及研究台数据备份。业务文件和图片留在本地，不纳入Git。

## 实际先后顺序

1. 续接用户已授权的普通Chrome Default和同一租约，通过 `scripts/ordinary-chrome-cdp.cjs` 连接已经打开的Chrome原生WebSocket。没有另启课程Profile或复制账号登录资料。
2. 从实际扩展研究台的 `imagegrabResearchData` 读取原20件商品，排除已完成木珠；严格检查剩余19件。
3. 在后台新建一张详情页，逐件导航；确认商品标题、参数和规范商品URL。通过扩展 `chrome.scripting.executeScript` 注入真实 `detail-capture.js`，滚动到详情并读取开放Shadow DOM中的图。
4. 枚举渲染的颜色/型号按钮，逐项激活、等待、读取尺寸、价格、库存和图片；不操作购物数量、购物车或购买。第一轮发现售罄规格被页面折叠，随后逐件展开“已售罄商品”补核，复用已下载图片URL，只补新图。
5. 通过真实扩展 `OPEN_RESEARCH` 导入资料，从实际本地存储确认对应货源已保存；保留预期/实际选项数、跳过原因和时间。
6. 使用 `chrome.downloads.download` 下载真实图片以及每件商品CSV、JSON，图片每组4个，逐组检查 `chrome.downloads.search` 完成状态。记录绝对下载路径、大小、MIME及错误，不把URL保存等同于文件下载。
7. 下载批次快照并运行下面的本地归档命令，复制实际文件、解码图片、核对规格数量及本地图片路径。浏览器原下载文件保留，以维持“打开文件夹”功能。
8. 独立读取非默认银色铃铛的5个尺寸，与已存40行/8种颜色比较；另读哑光粉色已售罄10个尺寸，与实际保存的价格和“库存不足”逐项比较。两次独立抽查通过。

实际本地命令（在插件根目录执行）：

```powershell
node scripts/ordinary-chrome-cdp.cjs
python -X utf8 scripts/archive-remaining19.py D:/Downloads/ImageGrab/remaining19-20261104/批次核验快照.json
npm test
node scripts/update-source-snapshot.cjs --date=2026-11-04
./scripts/build-extension.ps1
node scripts/verify-snapshot.cjs
```

历史浏览器执行函数保存在 `scripts/historical/collect-remaining19-20261104.js`，需在已授权且已加载扩展的研究台页面中由CDP `Runtime.evaluate` 执行；不是直接用Node运行的采集器。它使用真实扩展的 `ImageGrabOfferData`、`chrome.scripting`、`chrome.runtime`、`chrome.storage`、`chrome.downloads`。任务键为 `imagegrabRemaining19Job`，从实际商品URL与完成状态续接；源码不包含租约令牌或浏览器端点。应先核对该批原19件仍在研究台中，不适用于任意新的商品池。

## 本次修复

- 无规格名称的实际购买单价行被过滤：页面的“购买数量”组使用空标签。现在保留为“默认规格（页面未列名称）”，取该行真实价格和库存。
- 售罄规格的库存文字在 `.item-count-invalid`，并非常规 `.item-price-stock`。现按真实节点保留“库存不足”，已增加回归断言。
- 例：34颜色铃铛第一轮198行含一条页面区间参考，展开售罄后得到340行（34×10），不再用页面总区间代替该颜色尺寸的单价。
- 本地源码和安装包为1.5.2，19项测试通过。浏览器既有扩展最初为1.5.0；本次逐页注入了修正后的采集文件，真实业务结果已回写实际扩展存储。不能把这件事描述成已重载浏览器中的1.5.2安装包。

## 口径与边界

762行包含页面可选项下可展开的售罄规格。579按实际下载URL计，可能有同画面的不同尺寸或编码，不代表579张独立照片。多个尺寸共用一张颜色图时保留共享关系；页面没有专用规格图时留空，不借商品主图伪造对应关系。

售价和库存是采集时页面展示值，可能为老客价，未宣称所有采购数量阶梯都已采集。发货地按物流区读取；参数及品牌按页面保留，CCC未进行官方核验。未录制视频或下载商品视频，本次范围是资料、规格报价与图片。

可分享的数量与抽查证据：`evidence/2026-11-04/remaining19-download-verification.json`。逐文件SHA-256及完整业务数据在本地输出清单中。

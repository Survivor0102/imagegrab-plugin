# 货源比较筛选

版本：1.9.7

货源比较中的每条记录属于某个商品，因此筛选条件从所属商品继承。商品来源分为“榜单”“同款寻源”“手动”三类；榜单货源还会继承商品的榜单类别和商品大类。

货源比较支持以下筛选：

- 来源：全部、榜单、同款寻源、手动。
- 榜单类别：人气热销、近期趋势、实力优选等已登记的榜单类别。
- 商品大类：当前研究台登记的 1688 一级商品大类。
- 详情状态：已补全或待补全。以货源是否有详情采集记录为准。
- 发货地：已记录或待记录。
- 客服链接：已采集或待采集。

顶部的关键词搜索仍然有效，并且会与这些筛选条件叠加。筛选只改变当前列表的显示范围，不删除、不修改商品池和货源记录；“第二阶段 · 商品详情”的“当前筛选的商品”仍然只作用于商品池筛选，不会把货源比较筛选误当作商品详情任务范围。

筛选结果右侧会显示当前条件和记录数量。清除条件时，将各下拉框恢复为“全部”，来源恢复为“全部”。

# 榜单范围与自动采集

## 研究台中的范围

研究台的“榜单采集范围”由三部分组成：

1. **榜单类别**：人气热销、潜力新品、近期趋势。
2. **商品大类**：从已核实的1688一级商品类目中选择，例如居家日用品、美容护肤/彩妆、个护/家清、数码/电脑等。类目名称和 `cateId` 由同一个选项自动生成，不再手填，避免名称与实际榜单地址不一致。
3. **地区**：固定为中国，参数为 `countryCode=CN`。

点击“打开并自动采集”后，扩展按所选范围生成1688榜单地址，在后台标签页启动自动采集。采集结果会保存：

- 任务范围：榜单类别、榜单参数、一级商品类目、`cateId`、中国地区；
- 商品档案范围：同样的范围标签；
- CSV导出：增加上述范围字段。

## 商品列表与第二阶段范围

商品池顶部的“全部 / 榜单 / 同款寻源 / 手动”是**来源类型筛选**，不是完整榜单分类。选择“全部”或“榜单”时，可继续用两个下拉框筛选榜单类别和商品大类；组合含义为“榜单类别 × 商品大类 × 中国”。例如“近期趋势 + 玩具”只显示该范围下的榜单商品。选择“同款寻源”或“手动”时，榜单范围筛选隐藏，不影响这两类记录。

第二阶段“当前筛选的商品”使用商品列表当前完整筛选结果，包含来源类型、榜单类别、商品大类和搜索关键词。因此可先选“榜单 → 潜力新品 → 美容护肤/彩妆”，再批量补全这批商品。若选择“当前选中商品”，仅当选中项仍属于当前筛选结果时才会入队；“全部商品”仍按整个档案处理，不受列表筛选限制。

旧档案如果没有榜单范围标签，不会根据标题猜类别；选择具体榜单类别或商品大类时，这些未标记记录不会被纳入。

## 与页面上的“自动采集榜单”区别

- 研究台的“打开并自动采集”：先按选择的榜单类别和一级商品类目打开对应榜单，再启动采集，是本次新增的受控入口。
- 1688页面上的“自动采集榜单”：保留原有从当前页面开始采集的兼容入口。若从范围入口打开，范围会随任务传入；历史或手动打开的页面可能没有完整范围标签。

## 边界

- 目前实现的是一级商品类目范围，不是类目下的所有二级/三级筛选组合。
- 地区暂不提供选择，始终固定为中国。
- 完整Top1000、所有类目的实时采集仍未逐类验证；自动采集遇到登录、安全验证、列表不再加载或重复页面会停止并保留已采集结果。
- 旧商品档案没有采集范围时显示“历史记录 · 采集范围待补”，不会根据商品标题猜测范围。

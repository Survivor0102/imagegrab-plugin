# 安装与手动使用

## 安装当前版本

1. 将本仓库下载并解压到固定目录。
2. 在 Chrome 地址栏输入 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库的 `imagegrab-extension` 文件夹；该层应能看到 `manifest.json`。当前版本为 1.1.1。
6. 打开淘宝页面，必要时刷新，使内容脚本注入。

也可以解压与当前版本对应的 `dist/imagegrab-extension-1.1.1.zip`，然后加载其中的 `imagegrab-extension` 文件夹。1.0.0 ZIP 是历史版本。

## 下载当前页面里的图片

1. 正常登录淘宝，进入搜索结果或商品详情页。
2. 等待目标商品图片显示。源页面本身未加载的图片，插件不保证能发现。
3. 点击网页右下角“获取图片”。
4. 在新打开的“商品图片画廊”中向下滚动，使更多懒加载预览加载出来。
5. 根据画面和尺寸勾选需要的图片；Logo、装饰图和无关推荐图应排除。
6. 点击“下载选中”。也可以对单张图片点击“下载 PNG”。
7. 在 `chrome://downloads/` 中确认文件下载完成，并检查实际文件。

普通手动使用时，保存位置服从浏览器的下载设置。2026-11-03 那次 Playwright 接管的下载落入运行时临时目录，这是当次自动化环境的行为，不是插件固定的保存目录。

## 注意结果的含义

- “已提取 N 张候选图片”：表示扫描发现了 N 个图片地址，不是 N 个不同商品。
- “处理完成：N/N 张已启动下载”：表示已创建下载请求，不等于已确认所有文件落盘。
- 正常路径会将图片转换为 PNG；原图兜底下载的实际编码不保证是 PNG，不能只看后缀判断。
- 转换 PNG 不会增加原图分辨率，也不会自动把缩略图替换为高清原图。
- 当前插件不会自动搜索或翻页。1.1.1 会尝试关联页面可见的销量文字；口味规格尚未支持。淘宝搜索页已实测；详情页实测受平台访问异常提示阻断。
